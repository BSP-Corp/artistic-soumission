01Aperçu

Une soumission est chiffrée dans notre outil d'estimation, puis validée par un estimateur. À cet instant, Zoho vous l'envoie en JSON. Vous répondez ; votre réponse est stockée et réaffichée à côté de la soumission.

Déclencheur
Passage au statut Validé dans notre outil
Méthode
POST
Taille réelle
environ 5,6 Ko (JSON compact)
Rejeu
3 tentatives sur 5xx ou timeout. Jamais sur 4xx.
Idempotence
Clé = soumission.id, stable dans le temps
Votre réponse
200 ou 202, corps JSON libre

Nous journalisons chaque tentative de notre côté — code HTTP, horodatage, corps de votre réponse. Si vous ne recevez rien, nous pouvons dire en quelques secondes ce qui est parti et ce qui a été répondu.

02Conventions

Six règles valables partout dans le document. Elles évitent les mauvaises surprises au mapping.

  • noms métierAucune référence à notre fichier de calcul d'origine n'est exposée. Les noms sont stables et ne bougeront pas d'une version mineure à l'autre.
  • 0-100Les pourcentages sont des nombres entre 0 et 100. perte_pct: 10 signifie 10 %, jamais 0,1.
  • nullUn champ non saisi vaut null — pas 0, pas de chaîne vide. Les cases à cocher sont de vrais booléens.
  • CADTous les montants sont en dollars canadiens, arrondis à 2 décimales. Seul prix.prix_unitaire en porte 4.
  • tempsChaque durée arrive sous la forme { heures, minutes, minutes_totales } — à vous de choisir la plus commode.
  • tableauxLes lignes vides sont omises. Seule exception : ventilation_couts compte toujours exactement 7 lignes, dans le même ordre.
Versionnement. Le champ schema_version voyage dans chaque envoi. Un ajout de champ incrémente la version mineure et reste compatible. Une suppression ou un renommage passe en version majeure et vous est annoncé 30 jours à l'avance.

05Référence des champs

06Authentification

Un jeton secret partagé, transmis hors courriel. Chaque envoi porte en plus une signature du corps, pour que vous puissiez vérifier son intégrité indépendamment du transport.

Requête entrante
POST /votre-endpoint HTTP/1.1
Content-Type: application/json
Authorization: Bearer <JETON_PARTAGÉ>
X-Zoho-Signature: sha256=<HMAC-SHA256 du corps brut, clé = jeton>
X-Zoho-Event: soumission.validee
X-Zoho-Delivery: <identifiant unique par tentative>
X-API-Version: 1.2

Vérifier la signature

Calculez le HMAC-SHA256 du corps brut reçu, clé = le jeton, encodage hexadécimal. Comparez en temps constant — jamais avec ==, qui fuit la clé par le temps de réponse.

Node.js
import { createHmac, timingSafeEqual } from "node:crypto";

const attendue = "sha256=" + createHmac("sha256", JETON)
  .update(corpsBrut, "utf8").digest("hex");

const a = Buffer.from(req.headers["x-zoho-signature"] ?? "");
const b = Buffer.from(attendue);
const valide = a.length === b.length && timingSafeEqual(a, b);
C#
using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(jeton));
var hash = hmac.ComputeHash(Encoding.UTF8.GetBytes(corpsBrut));
var attendue = "sha256=" + Convert.ToHexString(hash).ToLowerInvariant();

var valide = CryptographicOperations.FixedTimeEquals(
    Encoding.UTF8.GetBytes(attendue),
    Encoding.UTF8.GetBytes(signatureRecue));
Codes de réponse. 200 ou 202 : reçu, nous n'insistons pas. 4xx : erreur définitive, nous ne réessayons pas — c'est le bon code si le contrat est violé. 5xx ou timeout : nous rejouons 3 fois, puis la soumission est marquée en erreur et rejouable à la main.

08Ce qu'il nous faut

Quatre éléments de votre côté pour brancher le premier envoi réel.

  • L'URL de votre environnement de testNous la configurons chez nous ; aucun redéploiement n'est nécessaire ensuite pour passer en production.
  • Le format de votre réponseSi votre analyse renvoie un verdict structuré, décrivez-le : nous l'afficherons tel quel à côté de la soumission, pour l'estimateur.
  • Vos limites sur les fichiers jointsNombre et taille maximale. Nous proposons de vous envoyer des liens signés plutôt que les fichiers dans le JSON.
  • Vos règles métierPour répartir : les règles déterministes restent chez nous, l'analyse contextuelle chez vous. Objectif — ne pas développer deux fois la même validation.
