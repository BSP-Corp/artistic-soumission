# Captures de validation

Les preuves des tests du protocole (`../montage-protocole-tests.md`) se déposent ici, une par
test, nommées `T06-seuil.png`, `T10-cout-matiere-avant.png`, `T10-cout-matiere-apres.png`…

Pourquoi dans le dépôt plutôt qu'en pièce jointe : une capture envoyée par message est perdue
pour celui qui n'était pas dans la conversation. Ici, la case cochée dans le protocole et l'image
qui la prouve arrivent ensemble, dans le même commit, et n'importe qui peut vérifier seul que la
série a bien été jouée.

Déposer l'image **et** cocher la case dans le protocole dans le même commit — l'une sans l'autre
ne prouve rien.
